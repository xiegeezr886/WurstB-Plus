# Rise Modern 风格 TargetHUD

Fabric 1.20.1 的 `TargetInfo` 替换为单个攻击目标卡片，保留模块 ID、已有位置和缩放配置。HUD 编辑器与聊天框预览本地玩家；默认固定位置，可用 `Follow Player` 跟随目标。

布局对照本地 Rise 6.9.5（`f58ef9c`）默认 Modern：48 高、32×32 头像、8 边距，名字与 Winning/Losing 状态、6 高渐变血条及一位小数血量。出现为 850ms 弹性缩放，最后攻击 1 秒后以 400ms 回收，血条使用 250ms 缓动。支持受伤头像反馈和可关闭粒子；背景按用户最新要求统一为 Glass。

实现使用项目的 MiSans、淡紫 `#B5BEF0` 与 NanoVG；根据布局和行为独立实现，不复制未声明许可证的 Rise 源码、字体、资源或渲染管线。玻璃采用卡片区域圆角蒙版与黑色 110/255 透明度填充。所有 HUD 共享最高 640×360、30Hz 更新的模糊背景，同一 NanoVG 帧最多更新一次；无可见卡片时不做模糊，窗口尺寸变化时重建对应缓冲，关闭渲染器时释放。背景采样保持屏幕坐标，避免跟随卡片动画拉伸世界。阴影以单次 NanoVG box gradient 绘制，不启用全屏 Bloom。生物目标沿用现有支持，僵尸、骷髅、苦力怕与村民使用原版游戏贴图脸部，其余生物保留图标占位。

第二轮原版风格对齐：血条改为固定纵向渐变。头像圆角 10、半像素细描边和柔和阴影，受伤直接调制贴图颜色，死亡显示原版骷髅脸；玩家头像按 Rise 使用基础脸部，不叠加帽子层。新目标血条由空槽填入，聊天框预览播放弹性出现，关闭聊天后保留 1 秒再收起；编辑器保持稳定尺寸方便拖动。保留工作区已有的优势/劣势本地化文案。

随后按“所有 HUD 背景替换为 TargetHUD 玻璃”的要求，统一 `HUDMod.drawBackground()`，并接入灵动岛与通知卡片自绘外壳。保留各模块的位置、尺寸、内容配色、按键高亮和通知淡入淡出；HUD 主题不再切换卡片材质，字体配色仍遵循原规则。TargetHUD 取消 Tint / Solid 外壳设置，避免旧设置绕过统一材质。

圆角按最新要求统一使用灵动岛规则：逻辑高度 23 时半径 11.5，高度 23–36 时平滑过渡到 8.5，更高的卡片保持 8.5；较矮或较窄的卡片限制为短边的一半。玻璃蒙版、填充、阴影、键鼠按压高亮及编辑器选择框均使用同一规则，并随模块缩放等比例变化。

统一玻璃验证：独立输出目录 `.dsh-tmp/hud-glass-build` 的 `build` 成功，50 项测试通过。实机开启全部 61 个 HUD（0 启用失败），随后分开核对 FPS、延迟、坐标、按键、背包、会话信息、Logo、TargetHUD、灵动岛和通知堆叠；0.75/1.5 倍模块缩放下背景采样正常，无玻璃渲染异常。测试客户端正常关闭后恢复原 HUD 配置。大量快速切换时出现两条已有 HUD 配置文件原子替换失败日志，未影响绘制，退出后原配置已恢复。截图为 `.dsh-tmp/hud-glass-{overview,notifications,scaled,final}.png`。使用独立输出避免本工作区其他并行构建改写 class 文件，验证 Jar 位于 `.dsh-tmp/hud-glass-build/libs/`。

目标由已有攻击事件接入（包括 Killaura 的实际攻击），不扫描附近实体，也不因准星路过自动选目标。数据每 tick 采样，近战优势每 200ms 更新一次；受伤粒子最多 24 个，头像变换复用固定尺寸纹理。胜负文字是按 1.20.1 血量、吸收、攻击力、护甲、附魔和抗性估算的满力度近战击杀次数比较，不代表实际战斗结果。

`TargetHudMotionTest` 覆盖超时、出现/回收终点、反向连续性、血量中途变化、切目标重置和异常生命值。

2026-11-15 验证：Fabric `build` 通过，50 项测试全部通过。独立 `opai-gui-qa` 世界实测编辑器玩家头像预览、Killaura 实际攻击生物、血量下降与停止攻击后的收起；超时后模块尺寸为 0×0，目标仍在附近时不会重新显示。日志无 TargetHUD 渲染异常。1920×1080、GUI 缩放 4、RTX 5070 Laptop 的预览/攻击截图采样为 234–254 FPS；该数字仅描述此次测试场景，不作为跨硬件性能保证。截图保存在本地 `.dsh-tmp/rise-targethud-{preview,combat,closing,hidden}.png`。

第二轮实机验证同日完成：Intel RaptorLake-S Mobile 核显、1920×1080、GUI 缩放 4，编辑器预览约 152 FPS、攻击约 172 FPS、死亡收起截图约 160 FPS。确认模糊只覆盖卡片、世界其余区域清晰，村民头像和受伤染色正常，死亡切换骷髅脸后卡片尺寸归零，无 TargetHUD / OpenGL 渲染错误。截图为 `.dsh-tmp/rise-targethud-refined-{preview,combat,death}.png`；不同硬件和场景的采样不作横向性能比较。

最新背景调整（2026-11-15）：按用户要求恢复 v1.5.1 的 HUD 背景绘制，取自 v1.5.1 标签的 HUDMod；圆角按用户后续确认保留当前灵动岛插值规则。TargetHUD 和灵动岛也使用公共背景，通知恢复该版本的黑色透明渐变、细描边和阴影。移除共享玻璃捕获与模糊，恢复 HUD 背景主题切换；浅紫强调色及当前内容、动画保留。以上玻璃说明与截图仅为此前迭代记录。
