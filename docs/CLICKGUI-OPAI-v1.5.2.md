# ClickGUI Opai 外观移植（v1.5.2）

目标：Fabric 1.20.1 / Java 17。参考本地 `reference/clients/OpaiBounce` 的 `6a6bc99`。
用户已确认保留当前分类，仅替换 Opai 外观；字体沿用现有 MiSans。
2026-11-14 用户补充的截图用于尺寸和配色：冷黑半透明面板、淡紫色启用行、深蓝文字。

## 保留的功能

- 分类：HUD、视觉类、移动类、客户端、战斗类、世界类、其他类。
- 辅助面板：目标、配置、字体、设置、主界面。
- 模块开关、按键绑定、原有设置与配置加载/保存入口。
- Navigator 保留当前界面结构和独立入口，共用 ClickGUI 配色及背景模糊；按用户确认，分类栏半透、功能栏不透明。

## 已移植的外观与交互

参考 `Panel.svelte`、`Module.svelte`、`Description.svelte`、`OpaiSetting.svelte`、
`Reveal.svelte`、`motion.ts` 和 `opai.scss`，用现有 NanoVG 渲染体系实现。
按用户最新要求，以 Opai 截图的实际游戏区域测量尺寸，不采用 v1.5.1 的紧凑尺寸。
截图为 2560×1599，去除视频黑边后游戏区域约 2512×1440；模块行高 64、面板宽约 496 像素。
使用 441 高的参考坐标系，内部宽 152、行高 19.6，经同一变换映射绘制、裁剪和输入坐标。
窗口分辨率改变时按高度等比缩放，Minecraft 全局 GUI 缩放设置保持不变。

| 项目 | 参数 |
| --- | --- |
| 面板 | 参考坐标宽 152，间距 8，圆角 7，标题高 21 |
| 模块行 | 参考坐标高 19.6，左右留白 10，字号 8.3；1920×1080 下行高 48、面板宽约 372 像素 |
| 颜色 | 标题 #13161f（96%），面板 #101016（69%），设置区 #1c1f2b |
| 启用状态 | 背景/强调色 #b5bef0，文字 #0c185c |
| 控件 | 淡紫色滑块/开关、冷黑输入框、内联选项列表、HSV 颜色选择 |
| 背景 | 世界画面先降至半分辨率，再执行水平/垂直各一次 4 px 模糊并线性放大；关闭时释放资源 |
| 动画 | 320 ms 打开缩放/淡入，指数展开，点击波纹，180 ms 开关滑动/颜色渐变 |

- 左键模块执行原有主操作；右键展开内联设置；中键绑定按键。
- 各分类和辅助面板标题左侧显示对应的现有 GuiIcon，淡紫色图标参考大小 9，标题与图标留白 5。
- 模块设置底部提供按键栏及 Toggle / Hold / Smart 三个动作选项，接入现有按键处理器。
- 按键栏及动作选项栏均采用参考半径 5 的圆角，保留现有尺寸、间距和点击区域。
- 绑定时 Delete/Backspace 清除绑定，Esc 或右键取消；沿用当前后端支持的键盘按键。
- 切换模式会清除该模块旧的普通、Hold、Smart 绑定，并保留同一按键上的其他命令。
- 仅有明确主命令的 Hack 提供模块绑定，避免将 HUD / 工具的第一个设置命令误当模块开关。
- 枚举下拉采用参考坐标宽度外扩 2 的选项框、勾选矢量图标、指数展开动画；选项高 20、列表最高 120，滚轮优先独立滚动。
- 颜色设置常驻显示 2.08 宽高比的饱和度/亮度面板与纵向色相条，拖出边界仍可继续调节。
- 颜色面板支持方向键微调、Shift 加大步长、Home/End 调整饱和度；黑色/灰色保留所选 HSV 位置。
- 当前 `ColorSetting` 保存 RGB，颜色选择器据此省略透明度条；原有独立透明度设置仍可使用。
- 文本和数值框支持点击定位、拖动选择、Shift 选择、Ctrl+A/C/X/V、Ctrl+方向键及 Home/End。
- 文本和数值在 Enter / 失焦时提交，Esc 放弃草稿；非法或非有限数值不会写入设置。
- 模块设置及全局设置面板的开关统一采用 180 ms 过渡，圆点位置、轨道/边框颜色、勾选透明度同步变化；
  每个开关保留独立动画状态，中途反向从当前进度继续。子项箭头保留原有过渡，嵌套控件保持相同左边距。
- 标题左键拖动、右键折叠；拖动默认吸附 5 GUI px 网格，Shift 可绕过。
- 每个面板独立滚动；底部细滚动条、Shift + 滚轮及方向键可浏览横向画布。
- Ctrl+F 打开搜索；Esc 先退出输入/搜索，再关闭界面。
- 右下角入口打开原有 HUD 编辑器。
- 面板位置、开合、滚动、显隐、层级及模块展开状态保存在 `wurst/clickgui-opai.json`。
- 保留现有面板位置、开合、滚动和展开状态；统一参考坐标映射，不再迁移为 66 宽的紧凑布局。
- 内联设置内容参考宽 132，开关行高 19.6、数值行高 20、输入框高 21；色盘、滑条及绑定栏同步等比缩放。
- 主菜单底图与界面合并到一次 NanoVG pass，静态渐变不执行模糊。世界中的模糊保持约 8 个原始像素的范围，
  模糊着色器处理像素数降至原来的四分之一，面板和文字仍按原始分辨率绘制。
- 画布外的面板跳过绘制；面板每帧只测量一次，复用布局数组；内联设置高度和辅助面板行列表每帧复用测量结果。
- CGUI 和导航器使用独立缓存的 GUI 超采样目标，最高 1.5 倍绘制后线性还原，保持现有字体、布局和输入坐标。
  目标上限约 4K / 4096 边长；正常 HUD 保留原分辨率及独立目标，避免每帧在两种分辨率之间重复创建帧缓冲。
  开关和选项勾线改为连续圆角笔画，最小参考线宽 0.65，改善细线的锯齿和断点。
- 长文本裁切改为按完整前缀二分测量，保留字距、空格和 Unicode 字符边界，减少逐字原生测量调用。
- 方块、物品列表、交易列表、文件等设置复用现有专用编辑屏幕。

`OpaiPanelLayout` 让绘制和点击检测共享尺寸，覆盖展开动画与滚动后的变高模块行。
不引入网页/CEF 运行时；Opai 的网页专用音乐、账号、实体预览等不属于此次 ClickGUI 外观替换。
