# Opai 世界 / 服务器列表与菜单动画

适用于 Fabric 1.20.1，参考本地 OpaiBounce 的 `ListScreen.svelte`、
`listScreen.scss`、`menuMotion.ts` 和 `opai.scss`。

世界和服务器选择界面使用 320 GUI 单位宽的半透列表、36 高的圆角条目、
30×30 图标与两排底部按钮。世界加载、服务器探测、加入、编辑、删除确认等
仍调用 Minecraft 原有实现；重新创建世界与 Wurst 服务器工具放在「更多」。
账户管理器共用同一列表、卡片间距、操作区和翻转动画，保留现有账号后端。
三页顶部大标题已移除；保留「更多」入口与账号会话 / 操作状态提示，列表位置保持原样。
三个界面使用中文按钮；按用户要求，按钮沿用全局黑色半透圆角材质，
不使用 Opai 的小圆角按钮。账号收藏、编辑、随机账号、清空、导入和导出位于「更多」。
三个列表共用按时间插值的圆滑滚动：连续滚轮输入累积目标位置，键盘选择平滑滚入可见区域，
列表缩短时同时约束当前位置与目标，点击按屏幕上的实际位置命中。
鼠标悬停和选中高亮采用从左到右逐渐变淡的浅紫渐变，分别平滑淡入、淡出；
移开鼠标后保留选中状态，切换条目时旧高亮渐退。动画状态仅保留可见条目。

按用户最新要求，开始菜单先用 240ms smoothstep 渐隐按钮、Logo、用户名及页脚，
完全消失后才打开目标界面。目标列表从侧面开始，以 700ms quint-out 翻转展开；
操作按钮和账号状态提示同步淡入。动画期间禁用列表操作，返回时先收起卡片，再淡入开始菜单。
全局壁纸保持静止；屏幕交接帧也绘制同一壁纸，避免原版全景背景闪现。
开始菜单在 `TitleScreen.render` 的 HEAD 接管完整绘制，跳过原版全景与入场淡入，
避免返回和切换时先画出原版背景。账号添加、编辑及直接登录的按钮同步中文与圆角材质。

这是 Java/NanoVG 原生适配；未移植上游 Web 弹窗、拖动排序、ViaVersion 和代理后端。
现有字体、浅紫主题及开始菜单布局沿用当前版本。

验证：独立游戏目录启动客户端，确认世界 / 服务器列表显示、服务器选择及编辑返回、
三个开始菜单入口及返回。录帧检查了先渐隐后翻转的顺序；动画测试覆盖慢帧、
侧面交接、透明度边界和反向动画。圆滑滚动测试覆盖连续输入、帧率独立性、边界及键盘滚入。
账号添加、收藏及编辑返回通过实机检查。测试世界只用于列表展示，未加载，未连接外部服务器。
Fabric 完整构建与 85 项测试通过（0 失败、0 错误）；最终移除大标题后 `assemble` 通过。
本地检查图包括 `.dsh-tmp/opai-menu-sequence.png`、`unified-menus-final.png`、
`smooth-scroll-check.png` 与 `highlight-gradient-check.png`（截图记录的是移除标题之前的验收）。
