# Moon Modern 交互完善（Fabric 1.20.1 / v1.5.2）

参考本地 moon-rebase 默认 Modern 模式的 ModuleRowWidget、CategoryPanel、FloatSliderWidget、IntegerSliderWidget，完善现有 CGUI，而非完整替换为 Moon 界面。

- 模块行右侧显示紧凑绑定键；按用户最终要求不显示模块/面板箭头，整行左键切换模块，右键展开设置，中键绑定。设置专用入口保留左键展开。
- 面板标题保持左键拖动、右键折叠，没有隐藏的左键折叠热区。
- 模块开关背景与文字采用 180ms 平滑过渡，快速反向切换不中断当前动画位置。
- 展开的设置区域增加浅紫色细引导线，保持原有控件尺寸和面板宽度。
- 滑块改为 Moon 风格的小圆角方形滑块；数值编辑/外部变化平滑过渡，拖动直接跟手，端点保持在轨道范围内。
- 说明悬停 450ms 后出现，移至指针下方或上方，显示模块名与说明正文，按用户要求移除底部按键提示，避免立即遮挡所点模块。
- 绑定标签每 250ms 刷新，未改动时不逐帧遍历绑定表；不引入额外全屏模糊、浏览器或新的渲染后端。

保留 RedFix 的八个模块分类、HUD 和客户端工具入口，保留当前面板位置/尺寸、浅紫色配色与开关屏动画。CGUI 的布局仍保存至 clickgui-opai.json，旧配置继续有效。导航器不使用这套内联控件，不受本次改动影响。

来源及 Apache-2.0 许可证随包位于 META-INF/licenses/moon-cgui/。

验证：Fabric build 与 75 项测试通过，包括整行开关区域边界与无隐藏展开热区、右键展开、中键绑定、无设置模块和设置专用入口；隔离客户端检查了 AimAssist 展开、滑块、绑定标签的布局。绑定键缩写单独测试覆盖 R CTRL / L CTRL / R SHIFT / PGDN。
