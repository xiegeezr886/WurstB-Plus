# NeoRaven 音乐播放器 / 灵动岛

Fabric 1.20.1 使用 NeoRaven 提交 `1a4ae731837f28087c263763cf176d9ec0261c37` 的音乐管理、网易云请求、MP3 解码、歌词与动画逻辑，适配 Java 17、NanoVG 和现有灵动岛。

## 入口与使用

- 从 Navigator / ClickGUI 的「其他」分类打开「音乐播放器」。关闭窗口后继续播放。
- 支持网易云推荐、搜索、歌单、二维码登录，以及播放队列、随机、循环、音量和进度跳转。
- 本地 MP3 放入游戏目录下 `wurst/music/local`，或拖入播放器；同名 `.lrc` 作为歌词。
- 点击封面或歌词按钮进入歌词页，支持逐字着色、平滑滚动和点击歌词跳转。
- 灵动岛显示封面、歌名、歌词、实际音频电平和进度；聊天界面展开后可切歌、暂停、跳转及打开播放器。暂停一段时间后恢复闲置状态。
- 独立「音乐歌词」HUD 使用 Opai 的右对齐滚动歌词与翻译，详见 [歌词 HUD](MUSIC-LYRICS-OPAI-v1.5.2.md)。

## 布局与材质

播放器采用 NeoRaven 的窄图标分类栏、五列推荐封面卡片、搜索歌曲列表、底部波浪进度播放条和独立歌词页。本地音乐与播放队列位于「我的」页。按最终要求，窗口改为原版 **840×520** 设计画布，28 单位外框圆角；恢复搜索框 20、卡片 16、播放条 18、播放按钮 17 单位圆角。保留固定浅紫配色、分类栏半透和主内容区不透明。游戏内复用低分辨率背景模糊，主菜单使用当前全局壁纸。

窗口按原版 `min(屏幕宽×92%/840, 屏幕高×92%/520)` 计算适配上限，基础主题缩放为原版默认值 1。音乐播放器模块新增 `GUI Scale`（0.5–2.0，默认 1，步长 0.05），放大不超过适配上限，打开期间实时更新布局。背景及透明分类栏保留此前定制。

内部歌词页采用原版结束时间选行、110ms 焦点渐变、46×字号基础行距、2.6 秒手动滚动回归、长句按唱词换行、逐行独立高亮宽度和翻译/罗马音回退。多行歌词按实际块高增加间距，避免与相邻歌词重叠；换行测量按歌曲及字号缓存。波浪进度采用原版波长、速度、3.24 线宽及 10%–14% / 90%–95% 振幅过渡。音量条恢复为扬声器左侧的内联控件。

页面切换增加 140ms 淡出、140ms 淡入及 10 单位纵向滑动，内容切换发生在全透明时；顶部搜索和账号区域保持固定，分类栏和播放控制持续可用，快速切换采用最新目标。删除首页时段问候。播放/暂停图标交叉渐变，波浪振幅与速度随播放状态平滑起停；进度跳转平滑收敛，拖动时立即跟手。底部播放栏共用主页圆形按钮的白色半透填充与轮廓材质；中间播放键采用浅紫色底与白色图标，不额外创建模糊缓冲。推荐、搜索和歌曲列表滚轮使用帧率无关的渐缓滚动，连续输入叠加目标位置，歌词滚动支持触控板小幅输入。封面、歌曲信息与控制图标统一中心线，图标按可见字形边界居中，长标题预留上一首按钮空间。

文本字体沿用客户端字体，图标使用上游 Material Icons；独立歌词 HUD 继续采用 Opai。没有移植 Onyx 渲染器、世界空间 3D 歌词、Android/LWJGL2 音频后端或随封面改变的配色。Native NanoVG 与原版 shader 的抗锯齿、阴影及波浪末端有差异，不宣称完整视觉 1:1。

交互细化：分类选中胶囊使用无过冲的渐缓滑动，卡片、歌曲、普通按钮及播放控制采用约 100ms 悬停渐变，播放键仅作 3% 轻微按压，不再悬停放大或回弹。进度悬停显示目标时间，并渐显渐隐；音量条淡入淡出，歌词开关平滑移动；右侧滚动条支持点击轨道和拖动，悬停时加宽。暂停后保留当前歌曲高亮，再次点击当前歌曲暂停/续播而不重播；空专辑不显示多余分隔点。歌单卡片仅保留一层低强度悬停反馈；分区标题使用次级文字，设置控件统一右侧对齐。缓冲或错误信息占用播放栏第二行，避免临时挤出第三行。推荐和搜索失败提供重试入口，加载提示加入轻量脉冲。快速反向切页保留位移方向，避免突然跳位；悬停状态仅保留当前可见控件。

## 实现边界

音频采用 JLayer 1.0.1.4 解码与 Java Sound 输出，独立于 Minecraft 音量；播放期间停用原版背景音乐。封面后台下载、主线程上传，限制缓存与并发，关闭客户端时释放音频与纹理。异步请求使用代次检查，取消登录或退出账号后旧响应不能恢复会话。

网易云服务可用性、歌曲版权和账号权限会影响搜索及播放。二维码生成已验证，尚未完成真人扫码确认及个人账号歌单测试。没有捆绑任何音乐录音。

## 验证

独立测试实例已验证本地 MP3 / LRC、在线搜索与歌曲播放、推荐封面、歌词、播放/暂停/跳转、进入世界继续播放，以及聊天界面的灵动岛操作。Java 17 独立音频测试覆盖暂停、暂停时跳转、恢复、EOF 回调、重播和停止。测试素材、账号数据和运行目录均保留在被忽略的 `.dsh-tmp` 下。

Fabric `build` 通过，显式启用测试共 141 项、0 失败、0 错误；覆盖原版窗口适配、歌词选行和换行、页面淡出后切换及快速反向导航、进度不越界和暂停波浪停止。更新后的音频状态与会话取消逻辑已验证。已检查发行 JAR 包含 JLayer、ZXing、Material Icons 及对应许可证。

此前实机检查分类栏可见背景透出，内容区不透明。原版窗口适配测试覆盖普通屏幕、竖屏、超宽屏及缩放上限；歌词测试覆盖前奏/间奏选行与换行后高亮不越界。

本轮独立实例（1000×700）已检查页面淡出/淡入中间帧、快速导航最终落点、播放按钮渐变及暂停后波浪收平。本地歌曲恢复后播放位置持续递增，暂停状态保持；前后跳转至 30% / 18% 正常，音频错误为空。截图确认播放栏玻璃轮廓、图文对齐、首页无问候，以及四行长歌词不再重叠。关闭播放器可正常回到主菜单。

后续实机验证了推荐列表滚动条拖动、歌曲行悬停覆盖层、暂停后的当前曲目高亮，以及进度拖动的目标时间提示。重复点击同一歌曲可暂停并从原位置续播，未重置进度；新增反向切页测试断言位移连续，141 项测试仍全部通过。
