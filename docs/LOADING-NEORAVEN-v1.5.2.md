# NeoRaven 世界加载动画

Fabric 1.20.1 使用 NeoRaven 提交 `1a4ae731837f28087c263763cf176d9ec0261c37` 的 `LoadingOverlay`、`M3LoadingIndicator` 与 `m3_loading.fsh`，适配为 GLSL 150 和当前 NanoVG 文字/背景。

## 动画与接入

- 保留原版四种 SDF 形态、900ms 形变、1800ms 旋转、EMPHASIZED 缓动和 5% 呼吸缩放，标准直径为 64 GUI 单位。
- 保留客户端壁纸、浅紫强调色和现有字体；短窗口按高度缩放，标题和状态文字位于动画下方。
- 接入世界准备、生成区块、接收地形、通用进度和连接服务器界面。生成区块显示实际百分比，不模拟加载进度。
- 保留原版世界加载、连接取消、旁白和加载完成退出逻辑；连接页继续使用现有按钮。
- 着色器只编译一次，绘制后恢复 OpenGL 状态，退出客户端释放程序与 VAO。着色器失败时记录错误并显示静态圆形作为降级。

主要实现位于 `neoraven/loading/`、五个 `NeoRaven*Mixin` 和 `assets/wurst/shaders/neoraven/m3_loading.frag`。上游 GPL-3.0 许可证及改编说明随包保留于 `META-INF/licenses/neoraven/`。

## 验证（2026-11-16）

- 离线完整构建通过，141 项现有测试全部通过。
- 1000×700、Java 17、Intel OpenGL 3.2 实机：进度、生成区块、接收地形三种界面均可渲染；多帧截图确认形态和角度变化，加载着色器状态为 ready。
- 实际打开隔离测试存档 `killaura-qa`，显示生成地形 100%，经过接收地形后进入世界，加载界面自动退出，游戏继续渲染；本次日志未发现加载 Mixin 或着色器错误。
- 服务器连接页已接入，但本轮未实际连接远端服务器，也未进行连接取消的运行验证。
- 同一客户端复核音乐歌词页：内容区和左侧功能栏为黑色，播放器外仍显示模糊游戏背景。
- 加载标题及进度标签按 Wurst 客户端语言翻译；中文资源覆盖生成地形、接收地形、通用处理、连接和常见世界进度提示。中文环境实测生成地形与接收地形截图正常；英文仍使用对应英文文案。
