# Opai Dynamic Island — Fabric 1.20.1

入口：HUD 分类 → 灵动岛（DynamicIsland）。默认开启、顶部居中，保留现有 MiSans 字体与 CGUI 的淡紫强调色。

左侧使用用户提供的 Wurst 手写 W Logo（`626FB848-0DFC-4DC6-B99F-EEBCC4BCB2B2.png`），保留原透明通道，等比适配为 128×128 资源，按 12×12 逻辑尺寸绘制。Logo 与品牌文字、CGUI 使用相同的淡紫强调色 `#B5BEF0`。

## 行为

- 默认胶囊显示 WurstB+、用户名、Ping、服务器和 FPS，逻辑高度 23。
- 模块开关通知显示 800ms，普通通知显示 3000ms；保留最多三条，同模块快速切换原位更新并延续开关动画。新增通知独立执行 160ms 淡入与上移，更新已有通知不会重复入场或改变顺序。
- Info 通知的图标底色和标题复用 Logo 的淡紫色 `#B5BEF0`，图标符号使用深色以保持对比度。
- 活动优先级：箱子内容 > 挖掘进度 > 通知 > Scaffold > 默认信息。
- Scaffold 显示可用方块数、最近两秒的消耗速率和本次开启后观察到的最大数量比例。计数沿用 Scaffold 的物品筛选、预扣数量及副手规则。
- 挖掘卡片从交互管理器的开始/持续/完成回调读取实际目标与进度；完成后显示 100% 并保留 450ms，中断后 150ms 自动回收。换目标或同目标重新开挖会重置进度动画。仅发数据包且没有本地挖掘进度的模块不会生成模拟进度。
- 普通箱子、陷阱箱、木桶及潜影盒使用实际菜单的格子预览，物品变化和点击显示 380ms 扩散反馈，关闭容器后保留 450ms 再收回。切换容器按菜单对象区分，复用窗口 ID 不会继承旧物品反馈。
- 容器界面开启时，左键点击灵动岛内的物品使用原版 QUICK_MOVE 快速取出；悬停显示格子高亮和原版物品详情。点击按实际缩放、展开尺寸及裁剪范围定位，只接受当前菜单且最近绘制的格子。关闭、隐藏、过期预览和持有鼠标物品时不执行转移；覆盖区域的点击与后续拖动、释放不透传到原版界面，避免意外丢弃物品。同一格子点击节流为 150ms。
- 按实际绑定的玩家列表键淡出，释放后恢复。关闭模块、断开连接或切换世界会清除活动状态。
- HUD 编辑器可拖动与缩放；拖动会取消“水平居中”，位置和缩放沿用现有 HUD 保存机制。
- 开启灵动岛时通知转入岛内，原 Scaffold 小岛与通知卡片停止重复绘制；关闭灵动岛后恢复原组件，并清除旧通知，避免重新弹出。跨线程模块通知保留触发时的开关状态，不读取延迟执行时的新状态；普通通知同样丢弃切换世界前排队的旧事件。

## 渲染与来源

参考 `reference/clients/OpaiBounce` 的 `Island.svelte`、`IslandNoticeIcon.svelte`、`ChestIsland.svelte`、`motion.ts`、`blockStats.ts`，固定提交 `6a6bc99`。来源和许可证见 `fabric/src/main/resources/assets/wurstpenguin/opai/NOTICE.txt`。

使用已有 NanoVG 渲染器、抗锯齿图形和物品图标缓存。外壳的阻尼弹簧保留速度并支持动画中途反向，文字不跟随外壳拉伸；游戏数据按 tick/实际操作回调获取，会话信息每 250ms 更新，文字宽度缓存最多 128 项。普通游戏画面复用 HUD 通道；容器界面只在其绘制完成后绘制一次灵动岛，避免被原版暗幕压暗。未增加浏览器或全屏模糊。

修复了 AutoChestAura 对箱子中心的视线检测：允许射线命中目标箱子本身，仍拒绝中途被其他方块遮挡的箱子。

当前项目没有真实音乐播放后端，因此没有添加模拟音乐/歌词内容。

## 验证

`IslandStateTest` 覆盖通知原位替换/容量/过期/逐条入场、活动优先级、方块补充与消耗、重置、不同帧率下的弹簧一致性及反向连续性。`IslandActivityTest` 覆盖挖掘完成/中断/换目标、非法进度、菜单切换/关闭保留期和跨世界清理。`IslandContainerViewTest` 覆盖缩放后的格子定位、边缘留白、动画裁剪和过期/跨菜单点击隔离。完整测试集 44 项通过。

独立 Java 17 / Fabric 1.20.1 QA 客户端验证默认胶囊、模块通知、Scaffold 卡片和 HUD 编辑器；通过现有测试接口与自动模块验证普通箱子、潜影盒的真实物品及数量预览，以及自动挖掘时随真实进度增长的卡片。截图确认容器预览不再被原版暗幕压暗，挖掘进度从 0% 增长至 15%。新增容器 Mixin 已在客户端正常加载，并实机检查了 1.5 倍缩放下的潜影盒显示。未注入鼠标或键盘输入；新增的快速取物入口仍需真人鼠标操作验收。截图保存在 `.dsh-tmp/island-*.png`，不进入版本控制。
