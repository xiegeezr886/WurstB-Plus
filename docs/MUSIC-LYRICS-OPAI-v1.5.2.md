# Opai 歌词 HUD

仅新增独立的 `MusicLyrics`（音乐歌词）HUD，接入现有 NeoRaven 播放器的歌词、翻译和播放进度。播放器内部歌词页、音乐信息卡片和灵动岛布局保持原状。

## 行为

- 默认开启；未选择歌曲时隐藏，HUD 编辑器中显示双语预览。
- 无背景、白色文字、右对齐；当前行不透明，相邻行 35%，更远行 8%。
- 采用 Opai 的 450×120 设计尺寸、38 行距、48 当前行位置；本客户端默认以 0.5 倍 HUD 缩放显示，可在 HUD 编辑器拖动、缩放或关闭。
- 切句使用 330ms CSS `ease-out`，中断动画从当前显示位置继续；只保留当前行前后各两行。
- 上下边缘淡出，长歌词省略；歌曲有翻译时显示小字号第二行，提供「歌词翻译」开关。
- 暂停时保留当前位置；无歌词时显示歌名。更换歌曲、重新启用或长时间未渲染时重置动画，避免旧歌内容残留。

## 来源与适配

参考 `OpaiBounce/src/opai/LyricScroller.svelte`、`musicMotion.ts` 的 `lyricSlide`、`MusicHud.svelte` 和 `public/components/musiclyrics.json`。复用当前 MiSans 字体与抗锯齿文本后端；CSS 边缘遮罩改用仅在边缘文本处绘制的透明度裁剪条带，文字阴影使用原生绘制。没有引入浏览器、额外音乐服务、音频或上游字体。

许可证、固定提交与源文件 SHA-256 随包保留在 `META-INF/licenses/opai-lyrics/`。

## 验证

Fabric 完整构建通过，133 项测试、0 失败、0 错误；动画测试覆盖中途切句、跨段跳转、换歌清理、前奏阶段和边缘透明度。独立单人测试实例确认双语编辑预览、无背景右对齐、多行淡化、实际 MP3/LRC 播放同步，以及跳回 6 秒并暂停后保持正确当前行。与灵动岛同步显示，未出现歌词 HUD 渲染异常。首次定位按实际游戏窗口计算，已有编辑器位置保留。
