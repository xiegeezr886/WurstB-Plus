# Moon 账户管理界面

> 当前状态（2026-11-16）：下面记录 Moon 移植阶段。按后续要求，主列表已改用与
> 世界 / 服务器界面共用的 Opai 卡片布局，顶部大标题移除，按钮采用中文与客户端原有
> 黑色半透圆角材质；加入翻转动画、圆滑滚动及渐变高亮。账号后端继续保留。
> 最终实现与验证以 [菜单说明](MENUS-OPAI-v1.5.2.md) 为准。

参考本地 `moon-rebase` 提交 `55cd694e898025531de94e61e169ba6eb221f9f3`
的 `AccountManagerScreen` 与 `MoonMenuButton`，适配 Fabric 1.20.1。

- 主列表宽 304 GUI 单位，36 行距、32 行高、选中左侧色条和当前账号标识。
- 两排 Add / Direct Login / Login、Remove / Clear List / Random Alt；左上角 Back。
- 按钮采用 Moon 的主题填充、半透明悬停、半高减一圆角；强调色沿用浅紫色。
- 保留当前全局壁纸、MiSans 字体；不是背景和字体完全相同的复制。
- 单击选择，250ms 内双击同一行登录，滚轮翻动，方向键选择，Enter 登录。
- More 保留收藏、编辑、导入、导出和登出。添加、编辑、直接登录表单使用同一套按钮。
- Clear List 经确认后清空保存列表，不登出；Random Alt 与 Moon 一样切换临时离线名称，不写入列表。
- 继续使用现有账号加密文件和登录实现；未引入 Moon 的 Microsoft 浏览器 OAuth 后端，在线登录仍受现有后端能力限制。
