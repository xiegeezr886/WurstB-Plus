# Opai 药水效果 HUD（Fabric 1.20.1）

仅替换 `PotionStatus` 的绘制实现；模块 ID、开关、位置、缩放及 Duration 设置沿用原配置。

参考 `reference/clients/OpaiBounce/src/routes/hud/elements/Effects.svelte`：

- 每个效果独立一张 32 高卡片，间距 4，圆角 6，宽度随名称与倒计时变化。
- 药水颜色用于图标、名称、等级与背景左侧的渐变着色。
- 使用 17 张 Opai 药水图标的 alpha 蒙版；生命提升复用恢复图标，其他效果使用游戏图标。
- 等级使用罗马数字 II–X，更高等级显示数字；一级不附加等级。
- 倒计时独立一行；不足 300 tick 时变红；负时长显示 `*:*`。
- 180 ms 飞入、淡出与位置补间。效果消失后移除对应状态；退出世界、关闭模块时清理。
- 无效果时游戏内隐藏；编辑器显示夜视与速度 II 预览。关闭 Duration 时使用紧凑单行卡片。
- 原生 NanoVG 绘制、已有 MiSans 字体，不引入浏览器运行时。

许可、来源与上游声明随包放入 `META-INF/licenses/opai-effects/`。

验证：Fabric build 与 66 项现有测试通过；独立客户端 HUD 编辑器预览确认图标、两行文字、渐变和自适应卡片宽度正常，位置移动及 0.75 倍缩放正常。当前实机检查使用编辑器样例，未逐项触发所有真实药水状态。

## 盔甲 HUD 同款样式（2026-11-16）

ArmorStatus 共用 OpaiStatusCard 材质：每件装备独立卡片，32 高、4 间距、6 圆角，名称与耐久分两行，180ms 出入及位置过渡。保留模块 ID、位置、缩放和 Durability 选项；关闭耐久后使用 22 高单行卡片。未穿盔甲时隐藏，编辑器用钻石套装预览。

装备图标优先使用实际 ItemStack 的 GUI 渲染，包含材质、染色和附魔；缓存未完成或不可用时显示实际模型图集精灵。图标捕获去重、拒绝全透明缓存，并在捕获前恢复裁剪/写入状态。耐久显示剩余 / 最大值及百分比，卡片着色、名称和数字按 100% 薄荷绿 #97DDB0、50% 金黄 #F3CF78、0% 珊瑚红 #FF756F 连续插值；图标保持装备原色。

已在独立测试世界检查钻石、下界合金、铁、金、染色附魔皮革图标，装备脱下、空装备隐藏和编辑预览，以及低耐久数字。没有将测试装备写入用户正式游戏目录。

带附魔的实际装备卡片叠加 3.6 秒周期的低透明度斜向淡紫光带，限定在卡片圆角内并绘制在图标和文字下方。普通装备不绘制这一层；只用一次渐变填充，不增加模糊缓冲或纹理读取。

最终验证：独立测试世界中同时装备 100%、50%、7% 耐久装备，卡片分别为绿、黄、红；附魔卡片连续截图可见淡紫光带移动，未附魔卡片没有该光带。141 项测试通过。
