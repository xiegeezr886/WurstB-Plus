后续修复与复测见[同日异常修复报告](NEOFORGE-FIXES-2026-11-21.md)；以下保留修复前的对照记录。

范围：本轮选择 MC 1.20.4、1.21.1、26.2 的固定整合包做离线单人验收。包与加载器不升级，不进入多人服务器。原包、正式版和本地候选分别记录；未登录、关错误提示窗退出 `0`、保存后超时强杀、未捕获的关闭异常均不计完整通过。

## 26.2：Technical Electrical Temporal Totality

整合包 `0.26.3.9`（Modrinth `ytAolSjB`）实际锁定 MC **26.2** 和 NeoForge `26.2.0.75`。原包 64 个顶层 JAR，加装后 65 个。发布 JAR SHA-256 为 `42f3d24de64f1cbe2478854423b4b832dcd173a7a9b000371fe1d90541aaf925`。各轮复制存档并核对包清单 SHA-512、各客户端文件和实际加载参数。候选仅替换本次从源码编译的类以及对应 Mixin 配置，并逐项比对与正式包的差异；不是发布包。

| 对照 | 结果与证据 |
|---|---|
| 原包 | [本轮原包](../build/neo-qa-262-20261121/26.2/baseline/result.json)登录，停服后保存三个维度，退出 `0`；无强杀、无崩溃报告。 |
| 正式 v1.5.2 | [原始诊断](../build/modpack-compat-v152-20261121/batch-technical262/diagnostic.json)：`EntityMixin` 的必需流体调用没有命中，登录前退出 `1`。实查 `26.2.0.75` 的 `Entity.updateFluidInteraction()` 将流体效果委托给 `EntityFluidInteraction`。 |
| 只修复流体调用 | [结果](../build/neo-qa-262-20261121/26.2/candidate/result.json)：越过第一处故障，随后自定义连接界面 `NeoRavenConnectMixin.drawLoading` 无绘制目标，仍未登录。 |
| 再修复连接界面绘制 | [结果](../build/neo-qa-262-20261121/26.2/final/result.json)：已登录并保存三个维度；60 秒内没有退出，测试工具终止了进程。两处可选效果在对应调用不存在时沿用包的行为，未关闭全局注入检查。 |
| 再关闭长期工作任务 | [结果](../build/neo-qa-262-20261121/26.2/workers/result.json)：已登录、停服后保存三个维度，进程自行退出 `0`；仍有 `WurstB-Shutdown` 未捕获异常，不算完整通过。 |
| 再提前客户端清理 | [结果](../build/neo-qa-262-20261121/26.2/clean/result.json)：登录、退出 `0`，不再出现关闭钩子异常；但停服时服务端线程刷新聊天字体触发渲染异常，未完成最终保存。不能用先前的自动保存替代停服保存。 |
| 最终候选 | 将本地聊天界面刷新交回客户端线程，不改玩家权限计算。[首次](../build/neo-qa-262-20261121/26.2/save/result.json)与[读取刚保存的世界](../build/neo-qa-262-20261121/26.2/readback/result.json)均成功登录、停服后保存主世界、下界和末地，自行退出 `0`。无强杀、崩溃报告或关闭线程未捕获异常；上游取消缓存任务时仍打印中断日志。两次候选 SHA-256 同为 `19487a16ce6092c434ef74cbd7498fb04fe2b422ed24fa5ba3f33f46434c0982`，首次写出的 `LastPlayed` 与复测读取的初值一致，复测后继续增长，两轮源存档均未改变。 |

[关闭时的线程记录](../build/neo-qa-262-20261121/26.2/final/closing-threads.log)显示 Baritone 的缓存任务在客户端关闭后仍然存活。核对 NeoForge 内嵌 Baritone 的构造器后，在客户端关闭时取消两个长期任务，允许已提交的缓存保存完成，并关闭 SeedCrackerX 的执行器。未修改游戏的退出看门狗。后续候选把原有客户端清理提前到模组加载器关闭前，正常完成后 JVM 兜底不重复执行。

## 其他版本

26.2 最终源码实际执行的 [Gradle 项目测试](../build/neo-qa-262-20261121/gradle-save.log)共 256 项，无失败、错误或跳过。本轮合计覆盖三个版本、三个固定整合包；仅 26.2 的本地修复候选通过完整验收，读回不重复计为另一个组合。未改 Forge 或发布新版本。

- [1.20.4 / Simply NeoForged](NEOFORGE-120x-QA-2026-11-21.md)：原包锁定 NeoForge `20.4.248`。正式 v1.5.2 声明最低 `20.4.251`，被加载器拒载。关错误窗口后退出 `0` 不能计为通过。
- [1.21.1 / Forgeulously Optimized](NEOFORGE-1211-QA-2026-11-21.md)：原包和正式加装组在无诊断辅助的条件下，均因 `CITResewnNeoPatcher` 写入只读 ZIP 失败，登录前退出 `1`。不能将这个共同故障归因于 Wurst。
- [26.3 / Simply Neoforged，历史对照](MODPACK-COMPAT-v1.5.2-2026-11-21.md)：此前正式版能登录、保存和读回，但有关闭异常。本轮不将 26.2 修复或验收结果外推到 26.3。

1.20.4 的内嵌 Cloth Config 声明允许 `20.4.248`，不代表完整客户端可以运行，未下调最低版本。1.21.1 另在仅限测试实例的 ZIP 写入诊断环境中复测：原包能登录并保存，但出现渲染异常；加装组因 Wurst 与内嵌 Java-WebSocket 重复导出同一个 Java 包而在登录前退出 `1`。以上两项均未获通过。
