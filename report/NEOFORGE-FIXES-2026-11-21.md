# NeoForge 1.5.2：已知异常修复与复测（2026-11-21）

本报告区分构建检查、离线单人验收和原整合包对照。一次单人验收要求玩家登录、停服后保存、进程正常退出，并能用相同的测试包读回刚写出的世界。多次启动同一组合只算一个组合。测试制品不作为发布物，未测试联机功能。

结论：26.2、26.3 的锁定整合包搭配修复后的测试客户端通过；1.21.1 在修订整合包上通过，锁定原包不通过；1.20.4 的原入口安全子集在旧加载器上通过，未放宽正式版最低要求。其他版本工程只有打包声明检查，不外推游戏验收结果。

## 依赖重复打包

1.21.1 正式包中，Java-WebSocket、netty-codec-socks、netty-handler-proxy 的 195 个类既在顶层又在内嵌 JAR。保留原有内嵌版本，去掉第二次解包；修正 17 个有相同问题的版本工程。检查全部 23 份 NeoForge 构建文件中的三个依赖，未改变只采用一种打包方式的工程。该 [回归检查](../scripts/tests/test_neoforge_network_packaging.py) 已接入 CI；这是 69 项声明检查，不是 23 份游戏实测。

1.21.1 的 Java 21 模块路径对照仅使用三个依赖：去重后能解析；分别恢复任意一个重复包都会报错。见[通过日志](../build/neo-1211-dependency-only-qa/unique.log)和[重复包反例](../build/neo-1211-dependency-only-qa/Java-WebSocket.log)。[游戏加载器测试](../build/neo-1211-dependency-only-qa/result.json)识别全部三个内嵌库，但原包的 CIT 启动故障仍阻止登录。此依赖样本不含客户端类，不能算是 1.21.1 客户端单人通过。
