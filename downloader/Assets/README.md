# WDownloader icon

The W mark comes from `fabric/src/main/resources/assets/wurstpenguin/opai/wurst-logo.png`, the same artwork used by `DynamicIslandMod`.

`WDownloader.png` fits that mark inside a white rounded tile with a subtle border and transparent outer corners. `WDownloader.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel variants for Explorer, the taskbar and the window icon. Both assets are local project artwork; no external logo service is used.
